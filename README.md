# SpeechTraining

Тренажёр устных ответов для macOS и Windows. Расшифровывает речь в реальном времени, выделяет завершённую реплику и добавляет ответ в чат. Поддерживает русский, украинский и английский, три длины ответа и русский перевод под оригиналом.

## Скачать

Готовые сборки доступны в [GitHub Releases](https://github.com/aillmdevel-tech/SpeechTraining/releases).

| Система | Архив | Запуск |
| --- | --- | --- |
| macOS 14+ на Apple Silicon или Intel | `SpeechTraining-macos-universal.zip` | Распакуй и открой `SpeechTraining.app`. |
| Windows 11, x64 | `SpeechTraining-windows-x64.zip` | Распакуй всю папку и открой `SpeechTraining.exe`. Среда .NET входит в архив. |

Сборка macOS подписана локальной подписью без нотарификации Apple. Windows-сборка распространяется без сертификата издателя, поэтому система может показать предупреждение при первом запуске.

## Быстрый старт

1. Открой **Настройки**, добавь свои ключи Gemini и ElevenLabs. В поле контекста можно описать тему, формат репетиции и свои предпочтения.
2. Выбери **Микрофон**, **Звук Mac** или **Звук ПК**. Можно включить оба источника. На macOS для системного звука понадобится разрешение на запись экрана. На Windows захват идёт с системного устройства воспроизведения по умолчанию.
3. Нажми **Слушать**. Промежуточный текст появляется в окне, окончательная реплика сохраняется в локальной истории. Можно также ввести вопрос вручную или запросить новый вопрос в режиме **Тренировка**.
4. **Ctrl + Shift + клавиша под Esc** включает и останавливает прослушивание. **Ctrl + Shift + Пробел** скрывает и возвращает окно. Если сочетание занято, приложение пробует запасное. Клавиша под Esc без модификаторов работает в окне вне поля ввода.

**Ghost** включает системную защиту окна при запуске. Она зависит от способа захвата. На macOS при захвате через ScreenCaptureKit видимое окно может попасть в кадр. Горячая клавиша скрытия убирает окно с рабочего стола. Прослушивание управляется отдельно.

## Данные

Аудио передаётся ElevenLabs во время прослушивания. Gemini получает текст для границ реплик и ответов, а также выбранный контекст при генерации. Ключи, настройки и история хранятся локально. На macOS используется папка `~/Library/Application Support/SpeechTraining` с ограниченными правами доступа. На Windows используется `%LOCALAPPDATA%\SpeechTraining`, настройки защищаются DPAPI текущего пользователя. Используй распознавание для репетиций и соблюдай правила организаторов и участников разговора.

## Сборка

- macOS с Xcode и Go — `./scripts/build-macos.sh`.
- Windows с .NET SDK 10, Go и PowerShell 7 — `./scripts/build-windows.ps1`.

Результаты сохраняются в `dist/`. Общий шлюз Gemini запускается дочерним процессом приложения на локальном адресе с одноразовым токеном. Окно, горячие клавиши и захват звука реализованы отдельно для каждой платформы.
